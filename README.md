## Course Structure

Every lesson follows the same three-part format:

1. **Theory** — formal definitions, worked derivations, and the reasoning behind each structure.
2. **Python Implementation** — the concept translated into short, runnable Python code.
3. **Practice Questions** — graded problems for self-assessment before the next lesson.
